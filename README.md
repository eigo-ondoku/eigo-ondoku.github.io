# 英語音読コーチ

好きな英文を登録して音読し、**ブラウザの中で動くAI**が発音（個々の音）を採点する、個人用の学習アプリです。
外部の有料サービス、クレジットカード、アカウント登録（公開用の GitHub を除く）は不要です。録音した音声はこの端末の外へ送信されません。

## できること
- **教材**：教科書・記事・スピーチ・歌詞など、好きな英文を複数登録できます。文ごと、または改行ごとに自動で分けます。各文に日本語訳とメモを書き込めます。
- **音読**：お手本の再生（通常・ゆっくり・単語ごと）→ 録音 → 採点 → 改善点の表示 → 合格で★。合格しても自動では次へ進みません。
- **意味**：「📖 意味」（M キー）を押すと、文の訳と、押した単語の意味が出ます。単語の意味は英和辞書 EJDict-hand（パブリックドメイン CC0、くじらはんど）を同梱し、初めて調べたときだけ読み込みます。訳が未登録の文は、パソコンの Chrome・Edge なら内蔵の翻訳機能（端末内で処理）で自動翻訳し、教材に保存できます。
- **通し読み**：4〜5文を続けて読む練習と、全文を通して読む練習ができます。全文で合格すると教材が「🏅マスター」になります。
- **記録**：文ごとの最高点・最新点・練習回数・合格状況、苦手な発音の集計（口の形・舌の位置・空気の通り道の図つき）、バックアップ。
- **書体**：BIZ UDPゴシック（SIL Open Font License）を同梱し、どの端末でも同じ字形で表示します。設定で「UDデジタル教科書体」（Windows 内蔵）や端末の標準書体に切り替えられます。

## キーボード操作（音読・通し読み）
| キー | 操作 |
|---|---|
| Space | 録音開始／停止（停止すると採点） |
| P | お手本（もう一度押すと停止） |
| S | ゆっくりお手本 |
| R | 自分の声を再生 |
| ← / → | 前の文／次の文 |

入力欄に文字を打っているときは反応しません。

## 採点のしくみ
| 項目 | 扱い |
|---|---|
| 個々の音の正確さ | **点数あり（100点満点）**。AIが聞き取った音を、発音辞書（CMU Pronouncing Dictionary）の正しい発音と1音ずつ照合します |
| アクセント・強弱／リズム／イントネーション | **点数なし**。このAIは音の種類を聞き分けるもので、強弱・抑揚を評価する根拠がないためです。参考として「声の高さの幅」と「文の途中の長い間」の数値だけを表示します |

- 点数 ＝ 正しく発音できた音 ÷（正しい発音の音の数 ＋ 余分に入った音の数）× 100
- 合格は「合格ライン」（標準85点。設定で60〜95点に変更可）以上、かつ読み飛ばした語がないこと。毎回同じ計算で採点し、挑戦回数による加点はありません。
- 次のような、ネイティブでも普通に起こるゆれは正解として扱います。
  - 弱く読む母音のあいまい化
  - water の t のように、t が軽い「ラ」に近い音になる弾き音
  - the や to などの弱い読み方と強い読み方
- 音読で自然に起こる次の変化も正解にします（同じ文の中だけ。英語教員・ALT の試用結果をもとに追加）。
  - 語末の破裂音（p t k b d g）を、子音で始まる語の前で破裂させずに止める・落とす（next day、Bright copper、up with）
  - 文末の p・t・k を破裂させずに止める（bus stop.、finish it?）
  - 語の境目で同じ（または声の有無だけ違う）子音が1つにまとまる（bus stop、this seat、is singing）
  - 語末の t/d と you などの y がつながる（did you、don't you）
  - t＋弱い母音＋n で t が喉で止まる（button、mittens）
  - 弱い母音＋l/n/m で母音が消える、語末側の L が「オ」のように響く（woolen、kettles）
  - 語末の th が次の語の影響で息だけになる・吸収される（with strings）、with を /wɪθ/ と読む
  - ng の前の i が「イー」「エイ」寄りになる（strings、things）
  - 母音の後の r が「アー」の響きになる（year、near）
  - ナチュラルスピードの決まった縮約（want to → wanna、have to → hafta、did you → dja、a lot of → a lotta）
  - 機能語の弱形・強形（I、was、of など）、really /riːli/
  - 1語ずつ丁寧に読んだときの、語末の子音のあとの短いあいまいな「ァ」（破裂の余韻）
  「誤り」と「自然な変化」のどちらでも説明できる場合は、標準の読みを優先して誤りとして指摘します。
  母音を足す誤り（「ト」「ク」「ル」）、R/L、TH、V/B、F/H、ng/n、sit/seat などは従来どおり指摘します。
- AIが別の音と判断しても、正しい音の確率がかなり残っている箇所は「判定が微妙（AIの聞き取り誤りの可能性）」と表示します。こうした箇所は苦手な発音の集計に入れません。
- 子音の後に余分な母音が入る誤り（good →「グッド」、book →「ブック」）も検出します。
- 辞書にない語（固有名詞・数字など）は採点対象外です。数字は英語のつづりで書くと採点できます。

### 精度と限界
- 発音判定AIは `wav2vec2-xls-r-300m-timit-phoneme`（Apache-2.0）です。アメリカ英語の読み上げ音声で学習されたもので、ブラウザ用には `robg/speako-phoneme-recognizer` の ONNX 版を使います。
- 学習データでの音素の誤り率は約8%です。日本語話者の音声や雑音のある環境では、誤判定がもう少し増える可能性があります。静かな場所で、マイクに近づいて読んでください。
- 初回は約355MBのダウンロードが必要です。2回目以降は端末に保存されたものを使います。
- 動作はパソコンの Chrome または Edge をおすすめします。**iPhone・iPad はメモリの制限で動かない可能性があります**（未確認）。

## 公開手順（GitHub Pages：無料・カード不要）
1. https://github.com で無料アカウントを作ります（メールアドレスだけで登録できます）。
2. 右上「＋」→「New repository」を押します。
   - Repository name：`ondoku`
   - **Public** を選ぶ（無料で公開ページを使うために必要です。公開されるのはアプリのプログラムだけで、あなたの教材や録音は含まれません）
   - 「Create repository」を押します。
3. 「uploading an existing file」を押します。`eigo-ondoku-site.zip` を展開し、**中身**（`index.html` と `assets` フォルダ）をドラッグ＆ドロップして「Commit changes」を押します。
4. リポジトリの「Settings」→ 左メニュー「Pages」を開き、「Branch」で `main` と `/(root)` を選んで「Save」を押します。
5. 1〜2分待つと、`https://（ユーザー名）.github.io/ondoku/` で開けるようになります。
6. パソコンの Chrome でその URL を開き、「設定」タブか「音読」タブで「AIを準備する」を押します（Wi-Fi 推奨）。


## ファイル構成
```
src/worker/asr.worker.ts   発音判定AI（ONNX Runtime Web）をブラウザ内で動かす
src/lib/recognizer.ts      画面からAIを使うための窓口（ダウンロード・保存・実行）
src/lib/g2p.ts             英文 → 正しい発音（CMU 辞書）
src/lib/phonemes.ts        発音記号の統一、許容するゆれの規則
src/lib/scoring.ts         照合・採点・アドバイス・参考値
src/lib/tips.ts            口と舌の動かし方の説明
src/components/MouthDiagram.tsx  口の断面図・正面図（音ごとの舌・唇・空気の流れ）
src/lib/tts.ts             お手本の読み上げ（端末内蔵のアメリカ英語音声）
src/lib/recorder.ts        録音（16kHz）
src/lib/meaning.ts         単語の意味（英和辞書）と文の自動翻訳
public/ejdict.tsv          英和辞書データ（tools/build-ejdict.mjs で EJDict-hand から作成）
src/views/*                教材・音読・通し読み・記録・設定の画面
```

## 動作確認の範囲
- 開発環境から本物のAIモデルにはアクセスできませんでした。そこで、同じ形式（入力は音声波形、出力は音素ごとの確率）の**テスト用モデル**を作り、ブラウザの擬似マイクにテスト音声を流して全体を確認しました。
  - 教材の登録と、AI未準備のときに「採点できません」と表示されること
  - AIのダウンロード・端末への保存・起動、ブラウザを再起動した後に保存済みモデルから起動できること
  - 録音 → ブラウザ内での分析 → 採点：読み飛ばし、TH→S、R→L、V→B を検出し、不合格と表示
  - 正しい音読で100点・合格・★。合格しても自動では次へ進まないこと。記録と苦手な発音の集計、次の文への移動
- 採点ロジックは、余分な母音、判定が微妙な箇所、辞書にない語、長文（132語で約0.1秒）、同じ入力で同じ点数になることを確認しました。
- **未確認：** 本物のモデル（約355MB）での判定精度。人の声に対して実際にどの程度正しく判定できるかは、使いながら確かめる必要があります。
