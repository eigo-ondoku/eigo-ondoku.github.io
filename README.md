# 英語音読コーチ

好きな英文を登録して音読し、**ブラウザの中で動くAI**が発音（個々の音）を採点する、個人用の学習アプリです。
外部の有料サービス、クレジットカード、アカウント登録（公開用の GitHub を除く）は不要です。録音した音声はこの端末の外へ送信されません。

## できること
- **教材**：教科書・記事・スピーチ・歌詞など、好きな英文を複数登録できます。文ごと、または改行ごとに自動で分けます。各文に日本語訳とメモを書き込めます。
- **音読**：お手本の再生（通常・ゆっくり・単語ごと）→ 録音 → 採点 → 改善点の表示 → 合格で★。合格しても自動では次へ進みません。
- **通し読み**：4〜5文を続けて読む練習と、全文を通して読む練習ができます。全文で合格すると教材が「🏅マスター」になります。
- **記録**：文ごとの最高点・最新点・練習回数・合格状況、苦手な発音の集計、バックアップ。

## キーボード操作（音読・通し読み）
| キー | 操作 |
|---|---|
| Space | 録音開始／停止（停止すると採点） |
| P | お手本（もう一度押すと停止） |
| S | ゆっくりお手本 |
| R | 自分の声を再生 |
| ← / → | 前の文／次の文 |

入力欄に文字を打っているときは反応しません。

## 採点のしくみ
| 項目 | 扱い |
|---|---|
| 個々の音の正確さ | **点数あり（100点満点）**。AIが聞き取った音を、発音辞書（CMU Pronouncing Dictionary）の正しい発音と1音ずつ照合します |
| アクセント・強弱／リズム／イントネーション | **点数なし**。このAIは音の種類を聞き分けるもので、強弱・抑揚を評価する根拠がないためです。参考として「声の高さの幅」と「文の途中の長い間」の数値だけを表示します |

- 点数 ＝ 正しく発音できた音 ÷（正しい発音の音の数 ＋ 余分に入った音の数）× 100
- 合格は85点以上、かつ読み飛ばした語がないこと。毎回同じ計算で採点し、挑戦回数による加点はありません。
- 次のような、ネイティブでも普通に起こるゆれは正解として扱います。
  - 弱く読む母音のあいまい化
  - water の t のように、t が軽い「ラ」に近い音になる弾き音
  - the や to などの弱い読み方と強い読み方
- AIが別の音と判断しても、正しい音の確率がかなり残っている箇所は「判定が微妙（AIの聞き取り誤りの可能性）」と表示します。こうした箇所は苦手な発音の集計に入れません。
- 子音の後に余分な母音が入る誤り（good →「グッド」、book →「ブック」）も検出します。
- 辞書にない語（固有名詞・数字など）は採点対象外です。数字は英語のつづりで書くと採点できます。

### 精度と限界
- 発音判定AIは `wav2vec2-xls-r-300m-timit-phoneme`（Apache-2.0）です。アメリカ英語の読み上げ音声で学習されたもので、ブラウザ用には `robg/speako-phoneme-recognizer` の ONNX 版を使います。
- 学習データでの音素の誤り率は約8%です。日本語話者の音声や雑音のある環境では、誤判定がもう少し増える可能性があります。静かな場所で、マイクに近づいて読んでください。
- 初回は約355MBのダウンロードが必要です。2回目以降は端末に保存されたものを使います。
- 動作はパソコンの Chrome または Edge をおすすめします。**iPhone・iPad はメモリの制限で動かない可能性があります**（未確認）。

## 公開のしくみ
- このリポジトリの `docs/` フォルダが、GitHub Pages で https://eigo-ondoku.github.io/ として公開されています（Settings → Pages → Branch: `main` / `/docs`）。
- 更新するときは、ソースを直したあと `npm install` → `npm run build:docs` で `docs/` を作り直してコミットします。

## 自分のパソコンで動かす場合（開発者向け）
```
npm install
npm run dev
```

## ファイル構成
```
src/worker/asr.worker.ts   発音判定AI（ONNX Runtime Web）をブラウザ内で動かす
src/lib/recognizer.ts      画面からAIを使うための窓口（ダウンロード・保存・実行）
src/lib/g2p.ts             英文 → 正しい発音（CMU 辞書）
src/lib/phonemes.ts        発音記号の統一、許容するゆれの規則
src/lib/scoring.ts         照合・採点・アドバイス・参考値
src/lib/tips.ts            口と舌の動かし方の説明
src/lib/tts.ts             お手本の読み上げ（端末内蔵のアメリカ英語音声）
src/lib/recorder.ts        録音（16kHz）
src/views/*                教材・音読・通し読み・記録・設定の画面
```

## 動作確認の範囲
- 開発環境から本物のAIモデルにはアクセスできませんでした。そこで、同じ形式（入力は音声波形、出力は音素ごとの確率）の**テスト用モデル**を作り、ブラウザの擬似マイクにテスト音声を流して全体を確認しました。
  - 教材の登録と、AI未準備のときに「採点できません」と表示されること
  - AIのダウンロード・端末への保存・起動、ブラウザを再起動した後に保存済みモデルから起動できること
  - 録音 → ブラウザ内での分析 → 採点：読み飛ばし、TH→S、R→L、V→B を検出し、不合格と表示
  - 正しい音読で100点・合格・★。合格しても自動では次へ進まないこと。記録と苦手な発音の集計、次の文への移動
- 採点ロジックは、余分な母音、判定が微妙な箇所、辞書にない語、長文（132語で約0.1秒）、同じ入力で同じ点数になることを確認しました。
- **未確認：** 本物のモデル（約355MB）での判定精度。人の声に対して実際にどの程度正しく判定できるかは、使いながら確かめる必要があります。
